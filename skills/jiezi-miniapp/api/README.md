# Bundled component API snapshot

These files belong to the `jiezi-miniapp` skill and are installed with
`dsh-jiezi`. They are read relative to the skill's resource base, so
an Agent can use them from an empty or unrelated workspace. No existing
mini-app, repository checkout, `node_modules`, or project-generated `.nsh`
directory is required for component discovery or API reading.

## Versions and layout

- `nsh/`: Native Shell **0.6.0** generated TypeScript declarations. The snapshot
  includes core (`index.d.ts`, `types.d.ts`), Base (`base.d.ts`), Mobile
  (`mobile.d.ts`), JSX/global declarations, and their supporting modules.
- `jiezi/native/`: JieZi adapter **0.2.0**, whose manifest records
  `jiezi.table@2` and `jiezi.collection@1`. It includes the generated
  `index.d.ts`, runtime JavaScript, package manifest, and adapter documentation.

Read [../references/components.md](../references/components.md) first for
component selection and minimal examples, then search these declarations for
the exact `Props`, data, event, and ref types. Large declaration files should be
searched and read in focused ranges rather than injected wholesale.

## New projects and version drift

The bundled snapshot is the baseline available before a project exists. Once a
project has been initialized, its generated declarations describe its actual
pinned Native Shell version. If they differ, do not silently mix APIs: identify
the versions and use the project/Host-compatible contract. The JieZi adapter's
runtime availability still requires Host feature detection through
`host.params.components`.

For a new project that uses `jiezi/native` and has no established staging step,
copy the bundled `jiezi/native/` directory to
`<project>/node_modules/jiezi/native`. This stages the plugin-provided adapter;
it is not an npm install and needs no app-side Rust/Cargo metadata.

## Repository maintenance

The runtime package never reads these repository paths; they are provenance for
maintainers only:

- Native Shell declarations: generated by the pinned `nsh` 0.6.0 tooling, as in
  `frontend/ios-host/Samples/demo/.nsh/types/nsh/`.
- JieZi adapter: synchronized from the tracked
  `frontend/ios-host/native/sdk/jiezi-native-ts/` package.

When either pinned contract changes, update the snapshot in the same change and
rerun the bundle tests, packed-artifact discovery check, and component example
build/typecheck. Do not edit generated declaration contents by hand.
